# Architecture decision records

> Last updated 2026-10-30 · reflects commit [`a894636`](https://github.com/m-danie/job-tracker/commit/a894636)

An ADR records one important decision: the context, what was decided, and what follows
from it. ADRs aren't rewritten when things change. A new one replaces the old one, and the
old one's status becomes "Superseded by …", so the history of the thinking stays.

To add one, copy [template.md](template.md) to the next number.
